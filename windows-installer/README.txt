HOW TO INSTALL
==============

1. Right-click install.bat -> Properties -> if you see an "Unblock"
   checkbox near the bottom, check it, then OK. (Windows does this to
   anything downloaded from the internet -- harmless, just needs a
   one-time ack.)

2. Double-click install.bat. A black window will open and do everything:
   find your Valheim install, install the mod loader, download the pinned
   mods, and drop in the custom plugin. Takes a minute or two.

3. If Windows SmartScreen pops up ("Windows protected your PC") click
   "More info" -> "Run anyway". This happens because the script isn't
   code-signed, not because anything is wrong with it.

4. When it finishes it'll show a green "Install complete". Leave the
   window open until you've read that, then press Enter to close it.

5. Launch Valheim through Steam as normal -- nothing special needed, the
   mod loader hooks in automatically. Join Game -> Direct Connect with
   the server address/password whoever's running the server gave you.

If something goes wrong, just run install.bat again -- it's safe to
re-run and will retry anything that failed.

If it still doesn't work, send whoever's running the server the full
text from the black window (right-click the title bar -> Edit -> Select
All, then Copy) rather than describing what happened -- it'll have the
actual error.
